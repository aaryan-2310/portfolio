# WLV-01 Exterior Radiator Panels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the two missing flanking radiator panels (louvered-strip design) on the WLV-01 exterior vessel, directly in the live Blender scene, as a pure geometry addition — no export, no engine wiring.

**Architecture:** All work happens through the Blender MCP tools (`mcp__blender__execute_blender_code` running `bpy` Python, plus `mcp__blender__get_object_info` for verification) against the already-open, live Blender session that has `wlv01.blend` loaded. Each side (Left/Right) gets 9 thin rectangular slat objects generated by a loop, matched to the existing hull material, then the file is saved and committed once at the end.

**Tech Stack:** Blender 4.x `bpy` Python API via the Blender MCP bridge. No web/Angular/PlayCanvas code touches in this plan.

## Global Constraints

- **Model-only.** Do not modify `wlv01_exterior.glb`, `worldline-lab/three/main.ts`, `worldline-lab/playcanvas/main.ts`, or anything under `src/app/worldline/`. Those are explicitly out of scope (see [2026-08-09-wlv01-exterior-radiators-design.md](2026-08-09-wlv01-exterior-radiators-design.md#explicit-non-goals-this-session)).
- **Every Blender MCP tool call requires a `user_prompt` argument** (a short string describing why you're calling it) — calls without it fail validation. Always include one.
- Placement: two strips flanking `Ext_Spine`, running Y from **−8 to −13** (5 units), X ≈ **±1.4**, Z center ≈ **0.2** (matches `Ext_Spine`'s cross-section center).
- Per-slat dimensions: **0.5 long (Y) × 0.35 wide (Z) × 0.04 thick (X)**, canted **15°** around the Y axis.
- **9 slats per side** (18 total), named `Ext_Radiator_L_0`..`Ext_Radiator_L_8` and `Ext_Radiator_R_0`..`Ext_Radiator_R_8`.
- Material: reuse `Ext_Spine`'s existing material — do not create a new material.
- The `get_viewport_screenshot` MCP tool was observed returning a byte-identical (stale/cached) image across three different camera setups in the design session. Treat a failed/unchanged screenshot as a known tooling issue to report, not a task blocker — bounding-box checks are the authoritative verification method for this plan.

- Produces: one temporary mesh object named `Ext_Radiator_L_0` at Y center ≈ −12.72, used as the pattern the loop in Task 3 will reproduce (this exact object gets deleted and regenerated in Task 3 — it exists here purely to verify the shape/orientation/material logic works before mass-producing 18 of them).

- [ ] **Step 1: Create the prototype slat**

Call `mcp__blender__execute_blender_code` with `user_prompt: "Creating one prototype radiator slat to verify dimensions, cant angle, and material assignment before generating the full 18-slat strip."` and this code:

```python
import bpy, math

def create_radiator_slat(name, x_center, y_center, z_center, cant_sign):
    bpy.ops.mesh.primitive_cube_add(size=1, location=(x_center, y_center, z_center))
    slat = bpy.context.active_object
    slat.name = name
    slat.dimensions = (0.04, 0.5, 0.35)  # X thickness, Y length, Z width
    slat.rotation_euler = (0.0, math.radians(15.0) * cant_sign, 0.0)
    spine = bpy.data.objects.get('Ext_Spine')
    if spine and spine.data.materials:
        slat.data.materials.append(spine.data.materials[0])
    return slat

slat0 = create_radiator_slat('Ext_Radiator_L_0', x_center=-1.4, y_center=-12.7222, z_center=0.2, cant_sign=1)
print("Created:", slat0.name, "dims:", tuple(slat0.dimensions), "loc:", tuple(slat0.location))
```

import bpy, math

# Remove the Task 2 prototype so this task produces a clean, complete set
old = bpy.data.objects.get('Ext_Radiator_L_0')
if old:
    bpy.data.objects.remove(old, do_unlink=True)

def create_radiator_slat(name, x_center, y_center, z_center, cant_sign):
    bpy.ops.mesh.primitive_cube_add(size=1, location=(x_center, y_center, z_center))
    slat = bpy.context.active_object
    slat.name = name
    slat.dimensions = (0.04, 0.5, 0.35)
    slat.rotation_euler = (0.0, math.radians(15.0) * cant_sign, 0.0)
    spine = bpy.data.objects.get('Ext_Spine')
    if spine and spine.data.materials:
        slat.data.materials.append(spine.data.materials[0])

Y_START, Y_END, N = -13.0, -8.0, 9
bay_width = (Y_END - Y_START) / N
created = []
for i in range(N):

- [ ] **Step 2: Verify no collisions with neighboring geometry**

Call `mcp__blender__execute_blender_code` with `user_prompt: "Verifying the 9 new Left-side radiator slats don't overlap Ext_AftFairing, Ext_RCS_Fwd_L_0/1, or each other."` and this code:

```python
import bpy

names = [f'Ext_Radiator_L_{i}' for i in range(9)]
boxes = []
for name in names:
    obj = bpy.data.objects[name]
    bbox = [obj.matrix_world @ v.co for v in obj.data.vertices]
    ys = [v.y for v in bbox]
    boxes.append((name, min(ys), max(ys)))

boxes.sort(key=lambda b: b[1])
for name, ymin, ymax in boxes:
    print(f"{name}: Y[{ymin:.3f},{ymax:.3f}]")

# Check adjacent slats don't overlap in Y
for a, b in zip(boxes, boxes[1:]):
    assert a[2] < b[1], f"OVERLAP between {a[0]} and {b[0]}"

# Check the whole strip stays clear of the aft fairing (Y <= -14.0) and fwd RCS cluster (Y >= -6.6... actually -5.39 is its far edge, so clear if strip max < -6.6 is not required, just confirm no overlap with fairing Y range and RCS Y range)
fairing = bpy.data.objects['Ext_AftFairing']
fairing_bbox = [fairing.matrix_world @ v.co for v in fairing.data.vertices]
fairing_ymax = max(v.y for v in fairing_bbox)
strip_ymin = min(b[1] for b in boxes)
assert strip_ymin > fairing_ymax, f"Strip (min Y {strip_ymin:.3f}) overlaps aft fairing (max Y {fairing_ymax:.3f})"

rcs = bpy.data.objects['Ext_RCS_Fwd_L_0']
rcs_bbox = [rcs.matrix_world @ v.co for v in rcs.data.vertices]
rcs_ymin = min(v.y for v in rcs_bbox)
strip_ymax = max(b[2] for b in boxes)
assert strip_ymax < rcs_ymin, f"Strip (max Y {strip_ymax:.3f}) overlaps forward RCS cluster (min Y {rcs_ymin:.3f})"

print("All collision checks passed.")
```

Expected: prints all 9 boxes in ascending Y order with no gaps/overlaps, then `All collision checks passed.` with no `AssertionError`.

If an `AssertionError` is raised, the loop math or the Task 1 reference numbers have drifted — stop and re-check Task 1's Step 2 output against the current scene before adjusting.

import bpy, re

pattern = re.compile(r'^Ext_Radiator_[LR]_[0-8]$')
all_names = [f'Ext_Radiator_L_{i}' for i in range(9)] + [f'Ext_Radiator_R_{i}' for i in range(9)]

for name in all_names:
    assert name in bpy.data.objects, f"MISSING: {name}"
    assert pattern.match(name), f"Name doesn't match convention: {name}"

for i in range(9):
    l = bpy.data.objects[f'Ext_Radiator_L_{i}']
    r = bpy.data.objects[f'Ext_Radiator_R_{i}']
    assert abs(l.location.y - r.location.y) < 0.001, f"Y mismatch at index {i}: L={l.location.y} R={r.location.y}"
    assert abs(l.location.x + r.location.x) < 0.001, f"X not mirrored at index {i}: L={l.location.x} R={r.location.x}"
    assert l.data.materials and r.data.materials, f"Missing material at index {i}"

print("All 18 objects present, named correctly, symmetric, and materialed.")
